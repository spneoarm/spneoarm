Four agents do the writing. Each one has one job. I do not name them here. None of them merge.

## How a change ships

1. **Plan** — I write the goal and the steps before any code.
2. **Build** — An agent makes one small change, on its own branch.
3. **Check** — Tests, typecheck, and lint run. CI runs the heavy tests.
4. **Review** — I read the diff. A second agent reviews it too.
5. **Ship** — The change goes up as a draft pull request. It merges only when I say so.
